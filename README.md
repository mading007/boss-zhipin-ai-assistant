# AI 求职助手（BOSS直聘 + 猎聘）

一个**半自动**求职工具：本地匹配排序 + 大模型生成差异化招呼语 + 手动投递面板。

> ⚠️ **本项目不自动投递、不模拟点击发送、不批量群发消息。**
> 所有打招呼动作都由使用者本人在浏览器中手动完成，脚本只负责「筛选和准备话术」。

---

## 为什么这么设计

求职平台的账号风控对「短时间高频主动打招呼 + 机械话术」极其敏感，容易触发功能限制甚至封号。
所以这里的分工是：

| 环节 | 谁来做 |
|---|---|
| 岗位采集 | 脚本（只读公开列表页） |
| 匹配打分、排序 | 脚本（本地计算） |
| 生成招呼语 | 脚本（调大模型 API） |
| **打开岗位、粘贴、发送** | **你本人手动** |

面板会提示建议节奏（一天 8~15 个、分散投递、点开后停留一会儿再发）。

---

## 功能

- **数据采集**：通过 Chrome DevTools Protocol 控制专用 Chrome 抓取 BOSS直聘 岗位结构化字段与 JD 详情
- **JD 合并**：按 `job_id` 把详情页的 JD 正文合并回列表数据（语义匹配依赖这一步）
- **双赛道画像**：`AI应用` 与 `自动化测试` 两套独立的技能栈、期望薪资、主打项目，互不干扰
- **中文语义匹配**：TF-IDF 对中文做了「英文按词 + 中文按 2/3/4 字 n-gram」切分（纯空格分词对中文会退化成 0 相似度）
- **打分可解释**：每条岗位都输出明细，例如
  `技术栈30.0｜经验9.0｜学历10｜薪资10｜语义18.4｜方向10.0`
- **招呼语按赛道路由**：投 AI 岗讲 RAG 项目，投测试岗讲自动化项目，不会答非所问
- **HTML 投递面板**：一键复制话术 + 打开岗位页、已投递/已忽略标记、localStorage 持久化、每日节奏计数

## 快速开始

### 1. 安装依赖

```bash
pip install pandas scikit-learn requests python-dotenv
```

### 2. 配置密钥

复制 `.env.example` 为 `.env`，填入你的 DeepSeek API Key：

```
DEEPSEEK_API_KEY=sk-your-api-key-here
DEEPSEEK_MODEL=deepseek-chat
```

> `.env` 已在 `.gitignore` 中，不会被提交。**不要把密钥写死在代码里。**

不配置也能运行，会自动降级为模板版招呼语（但模板话术重复度高，不建议用于实际投递）。

### 3. 采集岗位数据

需要先用 `boss-zhipin-scraper` 抓取岗位列表与 JD 详情，默认输出到
`~/.boss-zhipin-scraper/job-result/`：

```bash
python scripts/boss_cdp_raw.py --keyword "自动化测试" --city 北京 --pages 3 --detail
```

### 4. 生成投递清单

```bash
python AI投递boss简历_v2.py
```

输出：

- `apply_ready_list_ai.csv` / `apply_ready_list_qa.csv` —— 匹配清单底表
- `apply_helper_ai.html` / `apply_helper_qa.html` —— **双击用浏览器打开即可投递**

## 打分维度

| 维度 | 权重 | 说明 |
|---|---|---|
| 技术栈 | 30 | 岗位技能标签与画像技术栈的交集 |
| 语义 | 35 | JD 正文与个人画像的中文 TF-IDF 余弦相似度 |
| 经验 | 15 | 解析「经验不限/1-3年」等标签 |
| 学历 | 10 | 低于岗位要求直接归零 |
| 薪资 | 10 | 与期望薪资的比值 |
| 方向 | ± | 命中加分词 +2/个，命中排除词 -4/个 |

标题命中硬件/车载/智驾等不匹配方向的岗位会被直接剔除，不进入面板。
